# claude-setup

My shared Claude Code global settings.

I'm using this repo to share the global configuration I use with [Claude Code](https://claude.com/claude-code) — starting with custom output styles, with more global settings (agents, skills, hooks, permissions) to come.

## What's here

- [`output-styles/`](output-styles/) — custom output style profiles that change how Claude Code communicates (BLUF, Simplified Technical English + ADHD focus, Tech PM, Smart Brevity), with install and usage instructions.

## More coming

I plan to add more of my global `~/.claude` setup here over time so others can pick and choose what's useful.
